## 业务范围

角色为学员（STUDENT）、教务（ACADEMIC）、教练（COACH）、财务（FINANCE）和管理员（ADMIN）。公开注册只能生成学员账号；管理员负责分配员工角色和菜单。

四个业务模块：

1. 报名与入学：学员提交报名，教务审核，财务登记缴费，报名生效。
2. 培训预约与学时：学员申请时段，教务分配教练和车辆，教练登记训练结果与学时。
3. 题库与模拟考试：教练提交考试方案，教务审核发布，学员随机抽取 20 道题并交卷获得判分。
4. 退学与退费：学员申请退学，教务核定退费方案，财务登记退款，保留历史记录。

## 数据库分组（共 22 表）

1. 权限基础：`user_account`、`role`、`user_role`、`menu`、`role_menu`。
2. 人员与资源：`student_profile`、`coach_profile`、`training_vehicle`、`training_package`。
3. 报名缴费：`enrollment`、`payment_record`；报名审核人、审核时间、审核意见与状态保存在 `enrollment`。
4. 培训：`training_slot`、`training_booking`、`training_assignment`、`training_record`。
5. 考试：`question_bank`、`mock_exam`、`mock_exam_question`、`exam_attempt`、`exam_attempt_answer`。
6. 退学退费：`withdrawal_request`、`refund_record`。

## 关键规则

- 金额采用 `DECIMAL(10,2)`；业务 ID 采用 `BIGINT`；状态使用英文枚举；数据库命名使用 `snake_case`。
- 用户与角色为多对多；学员档案、教练档案不与账号 ID 混用。
- 开考后固定个人答卷的 20 道题和顺序，刷新不重抽；答卷明细保留正确答案快照，得分可复核。
- 已发布考试任务的题目快照不可原地修改；预约、分配和训练登记分别记录；同一时段的教练与车辆不得冲突。
- 退学后停止新增预约并取消未来预约；退款不得超过实际缴费；历史不删除。
