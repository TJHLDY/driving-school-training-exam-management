## 三、3 分钟把系统跑起来

### 1. 环境

- JDK 17 或以上（本机用 JDK 21，注意别用 JDK 8）
- MySQL 8.0.16 或以上
- IntelliJ IDEA（Maven 工程，用 IDEA 自带 Maven 即可）

### 2. 建库导数据

在 MySQL 客户端执行（**只执行一次**，别和分脚本重复执行）：

```sql
SOURCE <本项目路径>/database/all.sql;
```

脚本会新建独立数据库 `driving_school_v12`，**不会删旧库**。如果提示数据库已存在，先停下确认，不要忽略错误继续。

导完可以执行 `database/04_verify.sql` 自检，正常会看到 12 张表、5 种角色、100 道题。

### 3. 打开工程

IDEA 里 `File → Open`，选 `项目源码/` 这个目录（里面有 `pom.xml`）。

### 4. 配 JDK

`File → Project Structure → Project → SDK`，选 17 或 21，**不要用 1.8**。

### 5. 填数据库密码

把 `项目源码/src/main/resources/application-local.yml.example` 复制一份，改名为
`application-local.yml`（放在同一目录），把里面的 `password` 改成自己的 MySQL 密码。

这个文件已在 `.gitignore` 里，不会被提交，每人各写各的。

### 6. 启动

运行 `src/main/java/com/example/drivingschool/DrivingSchoolApplication.java`，
控制台出现 `Started DrivingSchoolApplication` 后，浏览器打开：

**http://localhost:8080**

## 六、常见问题

**启动报 `Port 8080 was already in use`**
之前有实例没关掉。用管理员 PowerShell 执行：
`Get-NetTCPConnection -LocalPort 8080 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }`

**连不上数据库 / Access denied**
检查 `application-local.yml` 里的密码；库名必须是 `driving_school_v12`（不是旧的 `driving_school`）。

**登录提示"用户名或密码错误"**
两批账号密码不一样：脚本自带账号是 `Demo@123`，组员账号是 `123456`。密码在数据库里是 BCrypt 哈希，不能直接看，忘记就重新注册一个或用管理员改。

**git push 报连不上 github.com**
本机 hosts 被加速器（Steam++ 之类）改过，把 `github.com` 指向了 `127.0.0.1`。
等加速器的本地代理起来再推，或者先关掉加速器。可以先执行 `git push` 重试一次。

**右侧菜单点进去 404**
菜单路径来自 `menu.route_path`，页面路径必须一致。已有路径：
`/users` `/roles` `/menus` `/enrollments` `/training` `/exams` `/withdrawals`，另有 `/profile` 个人中心。
