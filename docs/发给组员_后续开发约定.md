## 权限

学员负责自己的报名、预约、答题和退学申请；教务负责审核报名、安排培训、审核发布考试、核定退款；教练负责维护题目、提交考试方案和登记自己负责的培训；财务登记缴费及退款；管理员维护账号、角色、菜单。

公开注册只能获得 STUDENT 角色。一个用户可有多个角色，菜单由 user_role 连接 menu 读取，按 route_path 去重。menu 的一行表示一个角色的菜单项，同一路径在不同角色下可以有不同名称。后端仍须检查角色、记录归属和状态，不能仅靠隐藏按钮控制权限。

## 简化后的业务规则

### 报名与入学

- 一位学员保留一份报名记录，选择 C1 或 C2；教务确认该次报名约定的费用、学时后审核，不设套餐表。
- 状态：SUBMITTED → APPROVED / REJECTED；驳回后改原记录重新提交；通过后由财务一次登记全额线下缴费，转 ACTIVE；退费结算后转 WITHDRAWN。
- 应缴金额、约定学时由后端按教务确认值写入，学员不得自行改价。审批前可修改资料，已通过后不再改合同金额。缴费只允许 APPROVED 状态，重复请求返回已有结果，不再次收款。

### 培训预约与学时

- 一条 training_booking 就是一个单人培训时段。教务创建 OPEN 行，学员认领后为 PENDING，分配教练车辆后为 ASSIGNED，教练登记结果后为 COMPLETED；开始前可取消为 CANCELLED。
- 取消行保留，不复用历史记录；需要重新开放时由教务新增 OPEN 行。不做多人班、容量统计、候补和分次训练登记。
- 只有 ACTIVE 且没有处理中退学申请的学员可以预约。学员、教练、车辆的时间都不能重叠，车辆车型须与报名一致。冲突条件是“新开始 < 已有结束 且 新结束 > 已有开始”。
- 在事务内锁定涉及的账号、车辆及预约行，按固定 ID 顺序加锁；认领时条件更新 OPEN 状态，检查影响行数，防止两人抢同一时段。分配时检查冲突，不能只依靠页面检查。
- 教练只能登记分给自己的培训；有效学时不得超过实际时长，小时按 60 分钟计；累计学时只汇总 COMPLETED 行的 valid_hours。

### 题库与模拟考试

- 教练先建 DRAFT 考试任务，再维护该任务的题目，至少 20 道启用题后提交审核。题目属于一个任务，不设公共题库到试卷的中间表。
- 状态：DRAFT → SUBMITTED → PUBLISHED / REJECTED；驳回后可修改重提；发布后可 CLOSED。提交待审核、发布和关闭状态均不允许改题，避免历史成绩对应的题目变化；需要新版本时新建任务并复制题目。
- 每人每任务一次考试；随机抽 20 题，每题 5 分，20 分钟，90 分及格。开始考试时在同一事务中创建答卷和 20 条明细，保存 position_no；刷新恢复原卷，不重新抽题。
- exam_answer 的题目必须属于该答卷的考试，Service 写入时校验；外键本身不保证这项跨表业务规则。答题结束前接口不返回正确答案和解析。
- 后端检查截止时间并判分，超时按已保存答案结算为 EXPIRED；重复交卷返回原成绩。关闭考试只阻止新开答卷，已有答卷可以完成。成绩及解析仅供本人或获授权人员查看。
- 本包 100 道题是教学演示题，包含理论和业务流程题，不是官方驾考题库，不接外部考试或支付系统。

### 退学与退费

- 一份报名只保留一份退学申请；REJECTED 可修改原记录重提，不另建重复申请。状态：SUBMITTED → APPROVED / REJECTED → REFUNDED（仅 APPROVED 可以退款）。
- 仅 ACTIVE 学员可申请；先处理已开始未结束的培训，再提交申请并取消未来预约。SUBMITTED / APPROVED 期间禁止新增预约；驳回后恢复资格，已取消预约不自动恢复。
- 教务核定金额，不能超过报名实缴金额；财务一次登记与核定额相等的退款，允许核定 0 元并登记零额结算。事务内锁定报名和申请，登记凭证、置 REFUNDED、置报名 WITHDRAWN；重复操作不得重复退款。
- 保留历史缴费、培训和答卷，不清空记录；不单独维护另一份“学籍状态”。

## 两人需要对齐的接口

刘梓烨在工程根目录维护 api_contract.md，陈志鹏确认后接页面：逐项写明 URL、请求方式、参数、返回值、允许角色、页面模板和 Mapper 方法。

- Java ID 用 Long，JSON ID 用十进制字符串；金额用 BigDecimal，JSON 金额用两位小数字符串。
- 字段名：SQL snake_case，Java/JSON camelCase；时间使用 Asia/Shanghai，对外带 +08:00。
- JSON 返回 `{code,message,data}`；错误区分 400、401、403、404、409。分页 page 从 1 开始，pageSize 默认 10。
- 登录沿用 JWT HttpOnly Cookie 时，统一提供 CSRF 防护；BCrypt 密码校验、Redis 菜单缓存等按课程附加项实际完成并提供证据，不能只有配置没有功能。缓存角色或菜单变更后需失效。
